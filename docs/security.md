# مدل تهدید و چک‌لیست امنیتی (Security & Threat Model)

## دارایی‌ها (Assets)
- فایل‌های آپلودی مشتریان (محرمانه)
- پایگاه داده مشتریان، سفارشات و قیمت‌ها
- دسترسی‌های پنل ادمین و حساب‌های اعتباری B2B

## تهدیدها (Threats)
- آپلود فایل‌های مخرب یا بدافزار (RCE از طریق ImageMagick/Ghostscript).
- افشای فایل‌های طراحی مشتریان.
- دسترسی‌های غیرمجاز به فاکتورها یا سفارشات دیگران (IDOR).
- حملات DoS از طریق فایل‌های PDF حجیم یا Zip Bomb.
- تغییر دستی قیمت در کلاینت (Tampering).

## کنترل‌ها و چک‌لیست
- [ ] ذخیره‌سازی فایل‌های مشتریان در باکت خصوصی با Signed URLهای موقت.
- [ ] پردازش فایل‌ها (Preflight) در کانتینر Docker کاملاً ایزوله، Read-only با محدودیت شبکه.
- [ ] استفاده از `execFile` به جای اجرای دستورات شل در پردازش فایل.
- [ ] محاسبه نهایی قیمت منحصراً در سرور و نادیده گرفتن قیمت‌های ارسالی از سمت کلاینت.
- [ ] اعتبارسنجی کامل همه‌ی ورودی‌ها با Zod.
- [ ] بررسی Access Control در تمام کالکشن‌های Payload CMS.
- [ ] پیاده‌سازی Idempotency روی درگاه‌های پرداخت.
- [ ] ثبت کامل Audit Logs برای تغییرات حساس، قیمت‌گذاری‌های دستی، و دانلود فایل‌ها.
