# دیکشنری دامنه (Domain Model)

| معادل انگلیسی | معادل فارسی | توضیح |
| --- | --- | --- |
| Bleed | بلید | حاشیه رنگی اضافی دور تا دور کار برای خطای برش |
| Safe Zone | حاشیه امن | محدوده‌ای که عناصر مهم طراحی (متن، لوگو) باید داخل آن قرار گیرند |
| Overprint | اورپرینت | چاپ شدن رنگ روی رنگ زیرین بدون سفید کردن لایه زیرین |
| TAC (Total Area Coverage) | جمع رنگ | مجموع درصد رنگ‌های CMYK در یک ناحیه |
| Crease | خط تا | ایجاد خط روی کاغذ/مقوا جهت جلوگیری از ترک خوردن هنگام تا شدن |
| Die-cut | دایکات / دورگیر | برش با قالب برای اشکال غیر مستطیلی و خاص |
| Lamination | سلفون / لمینت | پوشش پلاستیکی برای استحکام و زیبایی |
| Hot Foil Stamping | طلاکوب / نقره‌کوب | چاپ با ورقه‌های فلزی و حرارت |
| Form | فرم چاپی | ورق بزرگی که کارهای مختلف روی آن چیده و چاپ می‌شوند |
| Format / Size | قطع / اندازه | ابعاد نهایی برش خورده کار چاپی |
| Grammage | گراماژ | وزن کاغذ در هر متر مربع (مثلاً 300 گرم) |
| Preflight | پیش‌بررسی فایل | عملیات بررسی سلامت و استاندارد بودن فایل چاپی قبل از لیتوگرافی/چاپ |
| Proof | پروف / پیش‌نمایش تاییدیه | فایل نمایشی برای تایید نهایی مشتری پیش از چاپ |
| Turnaround Time | زمان تحویل / فوریت | زمان لازم برای آماده‌سازی سفارش (عادی، فوری) |
