# Persian RTL UI

- UI باید کاملا راست‌چین (`dir="rtl"`) باشد.
- از Tailwind CSS با Logical Properties استفاده کنید (مانند `ms-`, `me-`, `ps-`, `pe-` به جای `ml-`, `mr-`).
- اعداد در نمایش باید حتما فارسی باشند (مثلاً با تابع `formatNumber`).
- تاریخ‌ها همیشه باید جلالی/شمسی نمایش داده شوند (با استفاده از `dayjs` و پلاگین `jalali`).
- از فونت "Vazirmatn" برای متن‌ها و فونت‌های نمایشی (مانند Morabba / Estedad) برای تیترها استفاده شود.
