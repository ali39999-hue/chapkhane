# Pricing Rule Pattern

- موتور قیمت‌گذاری یک تابع خالص (`pure function`) است.
- به هیچ عنوان از درون موتور قیمت کوئری به دیتابیس زده نشود، API خارجی فراخوانی نشود، و از تاریخ/ساعت سیستم (`Date.now()`) استفاده نگردد.
- وضعیت‌های لازم (مانند `PriceList`) به عنوان آرگومان به تابع پاس داده شوند.
- هر قاعده جدید باید همراه با Unit Testها با پوشش کامل لبه‌ها و خطاهای ممکن نوشته شود. (پوشش > ۹۰٪)
- از Zod برای اعتبارسنجی ورودی‌ها قبل از محاسبه استفاده شود.
