# Print Domain

واژگان و مفاهیم کلیدی چاپخانه:
- **Bleed (بلید):** حاشیه اطمینان برش. معمولاً ۳ تا ۵ میلی‌متر.
- **Safe Zone (حاشیه امن):** فاصله‌ی عناصر مهم از لبه برش.
- **Overprint (اورپرینت):** چاپ شدن یک رنگ روی رنگ دیگر به جای حذف (Knockout) رنگ زیرین (مخصوصاً برای متن مشکی روی زمینه‌های رنگی).
- **TAC (Total Area Coverage):** مجموع درصد رنگ‌های CMYK در یک نقطه. نباید از مرز مشخصی (مثلا ۳۰۰٪) بیشتر باشد.
- **Crease (خط تا):** برای تا کردن کاغذ و مقوای ضخیم بدون ترک خوردن.
- **Die-cut (دورگیر / دایکات):** برش قالب‌دار برای اشکال خاص.
- **Lamination (سلفون):** پوشش پلاستیکی مات یا براق روی کاغذ برای استحکام و زیبایی.
- **Hot Foil Stamping (طلاکوب/نقره‌کوب):** انتقال لایه نازک متالیک روی کار.
- **Form (فرم چاپی):** ترکیب و چیدمان چند کار در یک ورق بزرگتر برای چاپ.
- **Format/Size (قطع):** ابعاد استاندارد کار چاپی.
