# Preflight Check Pattern

- بررسی فایل‌های چاپی در یک Worker جداگانه (خارج از فرآیند وب) اجرا می‌شود.
- قواعد جدید در اسکریپت Worker تعریف می‌شوند (مانند بررسی رزولوشن، فضای رنگی CMYK، بلید، سایز).
- از ابزارهایی مانند Ghostscript، qpdf و ImageMagick از طریق `execFile` (نه شل اسکریپت مستقیم) استفاده کنید.
- هر قاعده خطایی با دسته‌بندی مشخص (`error`, `warning`, `info`) برمی‌گرداند.
- `error` مانع تولید می‌شود، `warning` نیازمند تایید مشتری است.
