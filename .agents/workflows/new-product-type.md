# Workflow: افزودن یک نوع محصول چاپی جدید

برای افزودن یک محصول جدید:
1. تعریف مدل داده در Collection های Payload (مانند اضافه کردن ProductType جدید).
2. افزودن منطق قیمت‌گذاری متناسب با آن (Tier, Area, PerSheet) در ماژول Pricing.
3. ایجاد فرم پیکربندی در کلاینت (`/print/[slug]/configure`).
4. نوشتن تست‌های جامع برای قیمت‌گذاری و جریان کاربر.
