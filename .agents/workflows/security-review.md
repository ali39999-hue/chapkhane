# Workflow: Security Review

بررسی چک‌لیست امنیتی طبق `docs/security.md` روی تغییرات اخیر:
- آیا ورودی‌ها با Zod ولیدیت شده‌اند؟
- آیا کلیدهای محرمانه هاردکد نشده‌اند؟
- آیا Access Control ها روی Collection ها رعایت شده است؟
- آیا آسیب‌پذیری‌های IDOR بررسی شده‌اند؟
- آیا مسیرهای پنل به درستی محافظت شده‌اند؟
