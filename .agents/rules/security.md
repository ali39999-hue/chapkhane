# قوانین امنیتی (Security)
8. فایل مشتری محرمانه است: باکت خصوصی، بدون URL عمومی، دانلود فقط با Signed URL کوتاه‌مدت و بعد از بررسی مالکیت.
9. Preflight و هر پردازش فایل فقط در Worker مجزا اجرا می‌شود، نه در پروسهٔ وب.
13. بازبینی امنیتی خودکار: قبل از اعلام «تمام شد»، خودت چک کن: کلید هاردکد نشده؟ ورودی با Zod ولیدیت شده؟ Access Control روی همهٔ Collection ها تعریف شده؟ مسیرهای پنل محافظت‌شده‌اند؟ خطاها stack trace به کاربر نشان نمی‌دهند؟ مشکلی بود خودت اصلاح کن.
14. هیچ داده‌ای بدون Zod validate نمی‌شود — نه ورودی فرم، نه Query Param، نه Webhook.
15. Idempotency: هر Callback پرداخت و هر Webhook باید idempotent باشد (کلید یکتا + بررسی تکرار).
16. Audit Log: هر تغییر وضعیت سفارش، هر تغییر قیمت دستی و هر دانلود فایل مشتری لاگ می‌شود (چه کسی، چه زمانی، از چه IP).
