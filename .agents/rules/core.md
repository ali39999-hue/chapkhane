# قوانین هسته (Core)
1. استک ثابت است: Next.js 15 App Router + TypeScript + Payload CMS 3 + PostgreSQL + Redis/BullMQ + Tailwind 4. هیچ تکنولوژی جدیدی بدون تایید من اضافه نکن.
2. کامنت‌گذاری: بالای هر فایل نقش فایل؛ بالای هر تابع مهم هدف + ورودی + خروجی. برای منطق دامنهٔ چاپ (قیمت، بلید، اورپرینت، TAC) توضیح فارسی هم بنویس.
3. فارسی و RTL از روز اول: کل UI راست‌چین، اعداد فارسی در نمایش، تاریخ شمسی در همهٔ تاریخ‌ها، فونت Vazirmatn.
4. Mobile-First: اول ۳۷۵px بساز و تست کن، بعد دسکتاپ. Touch Target حداقل ۴۴×۴۴px.
5. تمپلیت اول: قبل از ساخت هر چیزی از صفر، چک کن Payload یا اکوسیستم Next پکیج/پلاگین رسمی دارد یا نه.
18. ترمینولوژی: از docs/domain-model.md پیروی کن. اسم فیلدها انگلیسی، متن UI فارسی. هیچ‌وقت فینگلیش ننویس.
19. پول: همهٔ مبالغ عدد صحیح در واحد ریال (بدون اعشار، بدون float). تبدیل به تومان فقط در لایهٔ نمایش.
20. Migration: هر تغییر مدل داده باید Migration داشته باشد. هیچ‌وقت روی دیتابیس Production push مستقیم نزن.
